# Google Play listing: Korean (ko-KR)

- **App name:** KairoX86

## Short description

Android에서 그 시절 PC를 직접 조립해 DOS, Windows, 가지고 있는 PC 게임을 실행하세요.

## Full description

KairoX86로 1981년 IBM PC부터 펜티엄 시대의 기종까지, 그 시절 PC를 Android에서 직접 조립할 수 있습니다. 시작할 기종을 고른 다음 CPU, 메모리, 비디오 카드와 사운드 카드, 드라이브 등 어느 부분이든 바꿀 수 있습니다. 빈 하드 디스크와 플로피를 만들고, 가지고 있는 설치 디스크나 CD를 드라이브에 넣어 실제 기기에서처럼 DOS, Windows, 게임을 설치하세요. 데스크톱의 86Box에서 만든 기기도 그대로 추가할 수 있습니다.

게임패드나 PC 키보드와 터치 마우스를 포함한 화면 컨트롤로 플레이하거나, Bluetooth 또는 USB 마우스와 키보드를 연결하세요. 화면이 두 개인 휴대용 기기에서는 PC와 컨트롤을 서로 다른 화면에 표시할 수 있습니다.

소프트웨어와 게임은 포함되어 있지 않습니다. XT급 PC는 포함된 GLaBIOS로 실행되며, 다른 기종에는 각자의 BIOS가 필요하고 이는 가지고 있는 펌웨어에서 가져옵니다.

같은 앱을 KairoX86 GitHub Releases에서 무료로 다운로드할 수도 있습니다. Play 버전에도 같은 기능이 있습니다.

KairoX86는 86Box, GLaBIOS, XTIDE Universal BIOS를 사용하는 독립 프로젝트입니다.
