# Google Play listing: German (de-DE)

- **App name:** KairoX86

## Short description

Bauen Sie einen Retro-PC auf Android für DOS, Windows und Ihre PC-Spiele.

## Full description

Mit KairoX86 bauen Sie Ihren eigenen PC von damals auf Android, vom IBM PC von 1981 bis zu Rechnern der Pentium-Ära. Wählen Sie einen Ausgangsrechner und ändern Sie jedes Teil davon: CPU, Arbeitsspeicher, Grafik- und Soundkarten sowie Laufwerke. Erstellen Sie leere Festplatten und Disketten, legen Sie Ihre Installationsdisketten oder CDs ein und installieren Sie DOS, Windows und Ihre Spiele wie auf dem echten Rechner. Ein in 86Box auf einem Desktop-PC erstellter Rechner lässt sich unverändert hinzufügen.

Spielen Sie mit einem Gamepad oder der Bildschirmsteuerung, einschließlich einer PC-Tastatur und einer Touch-Maus, oder schließen Sie eine Bluetooth- oder USB-Maus und -Tastatur an. Auf einem Handheld mit zwei Bildschirmen lassen sich PC und Steuerung auf getrennte Displays verteilen.

Software und Spiele sind nicht enthalten. Ein PC der XT-Klasse läuft mit dem enthaltenen GLaBIOS; andere Rechner brauchen ihr eigenes BIOS, das Sie aus Ihrer eigenen Kopie der Firmware importieren.

Sie können dieselbe App auch kostenlos über die GitHub Releases von KairoX86 herunterladen. Die Version bei Google Play hat dieselben Funktionen.

KairoX86 ist ein unabhängiges Projekt auf Basis von 86Box, GLaBIOS und dem XTIDE Universal BIOS.
