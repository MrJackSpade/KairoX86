## Short description

Build a period PC on Android and run DOS, Windows and your own PC games.

## Full description

KairoX86 lets you build your own period PC on Android, from the 1981 IBM PC to Pentium-era machines. Pick a starting machine and change any part of it: CPU, memory, video and sound cards, and drives. Create blank hard disks and floppies, put your install disks or CDs in the drives, and install DOS, Windows and your games as you would on the real machine. A machine made in 86Box on a desktop can be added as it is.

Play with a gamepad or on-screen controls, including a PC keyboard and a touch mouse, or connect a Bluetooth or USB mouse and keyboard. On a two-screen handheld, the PC and controls can use separate displays.

Software and games aren't included. An XT-class PC runs with the included GLaBIOS; other machines need their own BIOS, which you import from your own copy of the firmware.

You can also download the same app free from KairoX86 GitHub Releases. The Play version has the same features.

KairoX86 is an independent project using 86Box, GLaBIOS and the XTIDE Universal BIOS.
