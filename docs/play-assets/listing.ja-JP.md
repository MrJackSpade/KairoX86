# Google Play listing: Japanese (ja-JP)

- **App name:** KairoX86

## Short description

Android で当時の PC を組み立て、DOS や Windows、お手持ちの PC ゲームを動かせます。

## Full description

KairoX86 は、1981 年の IBM PC から Pentium 世代のマシンまで、当時の PC を Android 上で自分で組み立てられるアプリです。最初のマシンを選んだら、CPU、メモリ、ビデオカードやサウンドカード、ドライブなど、どの部分でも変更できます。空のハードディスクやフロッピーを作成し、お手持ちのインストールディスクや CD をドライブに入れて、実機と同じように DOS、Windows、ゲームをインストールできます。デスクトップの 86Box で作ったマシンも、そのまま追加できます。

ゲームパッドまたは画面上のコントロール（PC キーボードとタッチマウスを含む）で操作できるほか、Bluetooth や USB のマウスとキーボードも接続できます。2 画面の携帯ゲーム機では、PC とコントロールを別々の画面に表示できます。

ソフトウェアとゲームは含まれていません。XT クラスの PC は同梱の GLaBIOS で動作します。その他のマシンにはそれぞれの BIOS が必要で、お手持ちのファームウェアからインポートします。

同じアプリを KairoX86 の GitHub Releases から無料でダウンロードすることもできます。Play 版にも同じ機能があります。

KairoX86 は、86Box、GLaBIOS、XTIDE Universal BIOS を使った独立したプロジェクトです。
