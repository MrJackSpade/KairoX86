# v1.5.1

- New game: a PC whose firmware you have not imported can be chosen, marked Firmware needed. Before the name, a Firmware page lists each file it needs: what it is (the board's BIOS, a card's video BIOS or firmware, an MT-32's ROMs), its file name, its folder in 86Box's firmware set and its size, what it does and why the PC needs it, and Choose file. Each file is recognized by its contents, whatever its name. Import all from a folder takes a whole set at once, and 86Box on GitHub opens 86Box's project page. Next waits until every file is there.
- Machine settings › Firmware links 86Box on GitHub too.
- Which hardware has its firmware is checked again after an import or a removal, without restarting the app.
- Library: the New game button beside search is its + alone, so the app's name fits beside it on a portrait screen. Its name is read out, and shows on a long press.
- Every language: the last English words in the app's screens are translated in all eight languages.

Install over v1.5.0 to keep your PCs and settings. Software, games and 86Box's firmware are not included. Both APK variants and the Play bundle have the same features.
