# v1.6.1-test.3

Test build of KairoX86, for IBM PC compatible games. It is not published to Google Play.

- Faster: 32-bit loads go straight into their destination register.
- Faster: device writes with paging off go straight to the device.
- Faster: a return at the end of a translated block links straight to where it returns, in place of the return cache.

Install over v1.6.1-test.2, v1.6.1-test or v1.6.0 to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
