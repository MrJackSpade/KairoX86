# v1.5.0

KairoX86's first release: an emulator for IBM PC compatibles, from the 1981 IBM PC to Pentium-era machines, running 86Box.

- Each library entry is a PC you build: start from a preset (IBM PC XT, 486 DOS PC, Pentium Windows 9x PC) or a custom PC, and change its machine, CPU, memory, video and sound cards and drives. It is kept as an 86Box machine folder, so a machine made in desktop 86Box can be added as it is.
- Create blank hard disks and floppies in the app, put install disks or CDs in the drives, and install DOS, Windows and your games as on the real machine.
- GLaBIOS is included, so an XT-class PC needs no firmware from you. For other machines, import the folder holding 86Box's BIOS and device firmware; each file is recognized by its contents, whatever its name.
- Play with a gamepad or on-screen controls, including a PC keyboard and a touch mouse, or a Bluetooth or USB mouse and keyboard. On a two-screen handheld, the PC and controls can use separate displays.
- MIDI music plays through FluidSynth with the included GeneralUser GS SoundFont or one you import, through an MT-32 or CM-32L synth (Munt, with that synth's firmware from you), or out to a MIDI device you pick.

Software, games and 86Box's firmware are not included. Both APK variants and the Play bundle have the same features.
