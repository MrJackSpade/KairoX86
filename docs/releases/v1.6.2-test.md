# v1.6.2-test

Test build of KairoX86, for IBM PC compatible games. It is not published to Google Play.

- No changes for KairoX86 itself: this build keeps every Kairo app on the same version.

Install over v1.6.1 or any v1.6.1 test build to keep games, settings and saves. Both APK variants and the Play bundle have the same features.
